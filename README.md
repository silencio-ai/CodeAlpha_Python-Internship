# CodeAlpha_Python-Internship
This repository contains my completed projects for the Python Programming internship at CodeAlpha. The internship empowers students to master Python fundamentals. Interns will work on real-world projects such as automation scripts, web applications, and data processing tools.
Completed Tasks
Task 1: Hangman Game
Goal: Create a simple text-based Hangman game where the player guesses a word one letter at a time.
Features: Uses a small list of 5 predefined words. It limits incorrect guesses to 6.  
Task 2: Stock Portfolio Tracker
Goal: Build a simple stock tracker that calculates total investment based on manually defined stock prices.
Features: The user inputs stock names and quantity. It uses a hardcoded dictionary to define stock prices and displays the total investment value.  
Task 3: Basic Chatbot
Goal: Build a simple rule-based chatbot.
Features: Takes input from the user like "hello", "how are you", "bye". It uses predefined replies like "Hi!", "I'm fine, thanks!", "Goodbye!".
