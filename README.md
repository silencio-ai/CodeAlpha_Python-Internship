​This repository contains my Python Programming internship tasks for CodeAlpha. The code uses functions to keep things clean and easy to run.
​Task 1: Hangman Game
A text-based game where you guess words letter by letter. You get 6 wrong guesses.
​Task 2: Stock Portfolio Tracker
Calculates the total value of your stocks. You input the stock name and quantity, and it multiplies it by set prices. You can save the summary to a file.
​Task 3: A Basic Chatbot
A simple bot that replies to standard greetings like hello, how are you, and bye.
​How to run:
Run each file directly in your terminal. Since they use functions, you can also import them into other scripts.
